# @deepseek-ai/dsh-client-ui-infinite-canvas

[English](README.md) | 中文

浏览器插件在侧边栏品牌行旁增加模式菜单，并使用 `@xyflow/react` 提供无限创作模式。Harness 模式仍然是现有的对话/工作区界面；无限创作模式是一个支持平移、缩放、移动和纵向调整文本节点、连线、删除、控制器和小地图的本地画布。每个节点提供独立拖动条，新建节点会选择最近的空闲位置，不再与已有节点重叠。

插件保留 React Flow 全局样式的原始选择器，同时使用基于设计令牌的 CSS Modules 编写产品样式。React Flow 的视口、控制器、小地图、连接点和连线沿用库定义的布局，并继续具备插件样式归属和热重载清理能力。

画布文档保存在浏览器 `localStorage`，优先使用当前会话，其次使用当前工作区，最后使用全局回退键。保存失败不会阻止内存中的继续编辑。插件不调用 Host API、不修改会话日志、不把画布内容发送给模型，也不执行 AI 节点。

插件注册到 `sidebar.brand.action` 和 `shell.overlay` 插槽，并在两处共享一个根级 store handle。覆盖层会让下方 Harness 界面保持挂载，并提供自己的模式菜单，确保用户可以返回 Harness 模式。两处菜单都通过共享的 body portal 渲染并朝视口内部展开，因此不会被侧边栏裁剪。

## 模型体验

默认无模型体验。画布内容是浏览器本地视图状态，不会进入模型请求。后续增加 AI 节点时，必须先定义明确的会话可见输入，才能把内容传给模型。

#### KV Cache 影响

无；此插件不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **仅本地保存**：画布文档不会在浏览器之间或 Host 工作区之间同步。
- **仅支持文本节点**：文件、图片、任务和 AI 执行节点暂缓实现。
- **没有导入导出**：首版没有文档传输格式。
